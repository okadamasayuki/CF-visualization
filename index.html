キャッシュ・フロー計算書 ジェネレーター

BS・PL・SSをまとめたCSVをアップロードすると、会社と四半期ごとにキャッシュ・フロー計算書と財務指標を自動作成します。

CSVの書式について

1行目に見出し、2行目以降に科目と金額を並べた縦持ち形式です。会社名と四半期の列を入れると、複数社・複数四半期を1ファイルにまとめられます(どちらも任意)。実際のデータは「データ」タブで表形式のまま確認できます。

アルファ工業,2025Q2,BS,現金及び預金,,17200
ブライト電機,2025Q1,BS,現金及び預金,8000,9500
  • 2四半期目以降は前期末を省略できます。直前の四半期の期末残高を期首として自動で引き継ぎます。
  • 四半期は 2025Q1 / FY2025Q1 / 2025年度第1四半期 / 2025年1Q / 2025-03 などの表記を解釈します。
  • 金額は 1,234 / ¥1,234 / △1,234 / (1,234) / -1,234 のいずれの表記でも読み取れます。
  • 科目名は別名に対応しています(例:売掛金・受取手形 → 営業債権)。同じ会社・同じ四半期の同じ科目に複数行あれば合算します。
  • 会社名・四半期を空欄にした行は、直前の行の値を引き継ぎます。
  • 会社名列がないファイルは、ファイル名を会社名として扱います。
  • SSと補足情報の金額は、支出・減少項目もすべて正の値で入力してください。

※ 営業利益がCSVにないため「税引前当期純利益 + 支払利息 − 受取利息」で推計しています。EBITDAとROICもこの推計値に基づきます。

計算上の前提(簡便法)
  • 利息及び配当金の受取額・利息の支払額・法人税等の支払額は、経過勘定を考慮せずPLの発生額をそのまま用いています。
  • 有形固定資産の取得による支出は「期末純額 − 期首純額 + 減価償却費 + 売却簿価」で逆算しています(売却簿価 = 売却収入 − 売却損益)。
  • 短期借入金・長期借入金・投資その他の資産はBSの増減額(純額)で表示しています。
  • 預け金は現金同等物に含めず、その増減を投資活動に表示しています。
  • 現金及び現金同等物はBSの「現金及び預金」と一致するものとしています。

詳細情報を入れて精度を上げる

BS・PL・SSから読み取れない情報を補うと、簡便法の仮定を減らせます。 区分間の振替が起きるため営業CF・投資CF・財務CFの各合計は変わります(それが分類の是正です)。 増減額と期末残高は、BSと articulate する事実なので原則として変わりません — ただし「現金同等物の範囲」を変えた場合と「換算差額」を入れた場合は、 会計基準どおりに増減額そのものが変わります。

現金同等物の範囲

「現金及び預金」のうち、取得日から3か月を超えて満期の到来する定期預金などは現金同等物ではありません。

除いた分だけ期首・期末残高が変わり、その資金移動は投資活動(定期預金の預入・払戻)として表示します。増減額そのものが変わります。

※ 期首・期末の2時点が必要なため、まとめて入れる場合はBSの科目として本体のCSVに 現金同等物に含めない預金 の行を追加してください(四半期をまたぐ引き継ぎも効きます)。

利息及び配当金の表示区分

日本基準では、継続適用を条件に次の2方式の選択が認められています(IAS 7でも同様に選択の余地があります)。

これは「情報」ではなく会計方針の選択です。区分間の振替なので増減額は変わりません。読み込んだ全社に適用されます。

フォーマットをダウンロードして一括で入れる

読み込み済みの会社・四半期をすべて並べたCSVを出力します。金額欄に記入してアップロードすると、 会社名と四半期が一致する行に反映します(既存のBS・PL・SSはそのまま残ります)。

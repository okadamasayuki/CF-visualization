キャッシュ・フロー計算書(間接法)

行にカーソルを合わせると、その行の算定式と補足が出ます。

計算上の前提(簡便法)
  • 利息及び配当金の受取額・利息の支払額・法人税等の支払額は、経過勘定を考慮せずPLの発生額をそのまま用いています。
  • 有形固定資産の取得による支出は「期末純額 − 期首純額 + 減価償却費 + 売却簿価」で逆算しています(売却簿価 = 売却収入 − 売却損益)。
  • 短期借入金・長期借入金・投資その他の資産はBSの増減額(純額)で表示しています。
  • 預け金は現金同等物に含めず、その増減を投資活動に表示しています。
  • 現金及び現金同等物はBSの「現金及び預金」と一致するものとしています。

財務指標

※ 営業利益がCSVにないため「税引前当期純利益 + 支払利息 − 受取利息」で推計しています。EBITDAとROICもこの推計値に基づきます。

詳細情報を入れて精度を上げる

BS・PL・SSから読み取れない情報を補うと、簡便法の仮定を減らせます。 区分間の振替が起きるため営業CF・投資CF・財務CFの各合計は変わります(それが分類の是正です)。 増減額と期末残高は、BSと articulate する事実なので原則として変わりません — ただし「現金同等物の範囲」を変えた場合と「換算差額」を入れた場合は、 会計基準どおりに増減額そのものが変わります。

現金同等物の範囲

「現金及び預金」のうち、取得日から3か月を超えて満期の到来する定期預金などは現金同等物ではありません。

除いた分だけ期首・期末残高が変わり、その資金移動は投資活動(定期預金の預入・払戻)として表示します。増減額そのものが変わります。

※ 期首・期末の2時点が必要なため、まとめて入れる場合はBSの科目として本体のCSVに 現金同等物に含めない預金 の行を追加してください(四半期をまたぐ引き継ぎも効きます)。

固定資産の売却

売却による収入の総額はBS・PLからは分かりません(BSには純額の増減、PLには売却損益しか載らないため)。

入力すると「固定資産の売却による収入」がこの金額になり、同じ額だけ「固定資産の取得による支出」も大きく表示されます(取得と売却の総額表示)。投資CFの合計と増減額は変わりません。

利息及び配当金の表示区分

日本基準では、継続適用を条件に次の2方式の選択が認められています(IAS 7でも同様に選択の余地があります)。

これは「情報」ではなく会計方針の選択です。区分間の振替なので増減額は変わりません。読み込んだ全社に適用されます。

フォーマットをダウンロードして一括で入れる

読み込み済みの会社・四半期をすべて並べたCSVを出力します。金額欄に記入してアップロードすると、 会社名と四半期が一致する行に反映します(既存のBS・PL・SSはそのまま残ります)。

データの読み込み

!
CSVの書式について

1行目に見出し、2行目以降に科目と金額を並べた縦持ち形式です。会社名と四半期の列を入れると、複数社・複数四半期を1ファイルにまとめられます(どちらも任意)。実際のデータは「データ」タブで表形式のまま確認できます。

会社名,四半期,区分,科目,前期末,当期末
アルファ工業,2025Q1,BS,現金及び預金,11700,15900
アルファ工業,2025Q1,BS,預け金,4000,4600
アルファ工業,2025Q1,PL,売上高,,52000
アルファ工業,2025Q2,BS,現金及び預金,,17200
ブライト電機,2025Q1,BS,現金及び預金,8000,9500
  • 2四半期目以降は前期末を省略できます。直前の四半期の期末残高を期首として自動で引き継ぎます。
  • 四半期は 2025Q1 / FY2025Q1 / 2025年度第1四半期 / 2025年1Q / 2025-03 などの表記を解釈します。
  • 金額は 1,234 / ¥1,234 / △1,234 / (1,234) / -1,234 のいずれの表記でも読み取れます。
  • 科目名は別名に対応しています(例:売掛金・受取手形 → 営業債権)。同じ会社・同じ四半期の同じ科目に複数行あれば合算します。
  • 会社名・四半期を空欄にした行は、直前の行の値を引き継ぎます。
  • 会社名列がないファイルは、ファイル名を会社名として扱います。
  • SSと補足情報の金額は、支出・減少項目もすべて正の値で入力してください。

科目マッピング(算定ロジックファイル) 組み込みの対応を使用中

社内の勘定科目が一般的な名前と違う場合に使います。「どの科目を、どの項目に、+と−のどちらで反映するか」だけを 定義したCSV(金額・会社・会計期間は書かない)を読み込ませると、組み込みの対応より優先して CF計算書・財務指標・全社比較のすべてに反映されます。 まず「現在の算定ロジックをダウンロード」で今の対応表を取り出し、科目名を書き替えて読み込ませてください。

マッピングCSVの書き方

1行目に見出し、2行目以降に「科目, 反映先の区分, 反映先の科目, 符号」を並べます。

科目,反映先の区分,反映先の科目,符号
現金・預金(3ヶ月以下),BS,現金及び預金,+
減価償却累計額(建物),BS,有形固定資産(純額),-
受取利息及び割引料(営業外),PL,受取利息及び受取配当金,+
受取利息及び割引料(営業外),PL,税引前当期純利益,+
人件費・従業員給与,PL,税引前当期純利益,-
  • 同じ科目を複数行書くと、複数の項目へ同時に反映されます。PLに税引前当期純利益の行がない場合は、収益の各行を「税引前当期純利益 +」、費用の各行を「税引前当期純利益 −」にも割り当ててください(法人税等の行は除く)。
  • 反映先の区分は BS / PL / SS / 補足 / 詳細、反映先の科目はテンプレートCSVにある正式名です。
  • 符号は +(足す)か -(引く)。減価償却累計額や貸倒引当金のような控除科目は - にします。
  • マッピングに書いた科目はその指定どおりに、書いていない科目はこれまで通り組み込みの対応で取り込みます。
  • 共有フォルダに接続していれば mapping.csv として保存され、全員に同じマッピングが適用されます。

共有フォルダ 未接続

社内の共有フォルダ(ネットワークドライブ、OneDrive・Google ドライブの同期フォルダなど)を指定すると、 読み込んだデータと詳細入力をそのフォルダに保存し、次からはそこから読み込みます。 同じフォルダを見ている人どうしでデータを共有できます。

フォルダの中身と、共同利用のときの注意

指定したフォルダの中に、次の構成で読み書きします。専用のフォルダを指定してください。

<共有フォルダ>/
  data/         読み込んだCSVをそのまま置きます
  overrides/    詳細入力を 会社×四半期ごとのJSONで置きます
  settings.json 表示区分などの設定と、最終更新の記録
  • ファイル単位で「最後に保存した人が勝ち」です。会社×四半期ごとにCSVを分けておくと、同時に作業してもぶつかりにくくなります。
  • 他の人がフォルダを更新すると、このページに戻ったときに案内が出ます。読み込むまでこちらの表示は変わりません。
  • 自動書き出しでは、フォルダにある他のファイルを消しません。整理したいときだけ「完全に同期」を使ってください。
  • 接続したフォルダはブラウザが記憶します。次に開いたときは「共有フォルダに再接続」を押すと、選び直さずに使えます。

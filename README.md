# CF-visualization

貸借対照表(BS)・損益計算書(PL)・株主資本等変動計算書(SS)をまとめた**CSVファイルをアップロード**すると、**会社と四半期を選ぶだけ**で財務指標のサマリーと間接法によるキャッシュ・フロー計算書を自動作成して表示する静的Webアプリです。複数社・複数四半期をまとめて読み込み、前年同期比や時系列で比較できます。

## 機能

- **CSVアップロード** — ドラッグ&ドロップまたはファイル選択。BS・PL・SSを1つのファイルにまとめて読み込みます
- **複数社・複数四半期の一括読み込み** — `会社名` と `四半期` の列を入れれば1ファイルに何社・何期でも。2四半期目以降は `前期末` を省略でき、前の四半期の期末残高を期首として自動で引き継ぎます
- **財務指標のサマリー(前年同期比)** — EBITDA・ROIC・運転資金・有利子負債・ネット有利子負債・預け金・自己資本比率などを、前年同期と並べて増減・増減率つきで表示
- **預け金・借入金の推移** — 選択中の会社について直近10四半期を折れ線で表示(前四半期差の表示にも切り替え可)
- **全社比較ビュー** — 選択中の四半期について、会社別サマリー表(並べ替え可)と、指標を切り替えられるランキングチャート
- **データタブ** — アップロードしたCSVをそのまま表形式(スプレッドシート風)でプレビュー。選択中の会社・四半期のファイルを自動で開きます
- **詳細入力タブ** — 簡便法の仮定を減らす詳細情報を、画面から直接入力/テンプレートCSVをダウンロードして一括アップロード
- **算定ロジックタブ** — CF計算書の行を選ぶと、どの科目をどの符号で足し引きし、どの区分に反映されるかを図示。全行の算式一覧と、簡便法の仮定・解消方法も掲載
- **タブ構成** — サマリー / 推移 / CF計算書 / 全社比較 / データ / 詳細入力 / 算定ロジック の7タブ(矢印キーでも切り替え可)
- **文字コード自動判定** — UTF-8(BOM有無どちらも)と Shift_JIS(Excel保存のCSV)に対応
- **表記ゆれの吸収** — 科目名の別名、`△1,234` / `(1,234)` / `¥1,234` / 全角数字などの金額表記に対応
- **CF計算書の自動生成(間接法)** — 営業・投資・財務の3区分と小計・期首/期末残高を自動計算
- **ウォーターフォールチャート** — 期首残高 → 営業CF → 投資CF → 財務CF → 期末残高の推移を可視化(ホバーで詳細表示)
- **整合性チェック** — BSの貸借一致、CF計算書とBSの現金残高の一致、SSと純資産増減の整合を会社・四半期ごとに自動検証
- **テンプレートCSVのダウンロード** — 空欄のひな形を出力。読み込んだ内容をCSVに書き戻すこともできます
- **ダークモード対応**・**入力の自動保存**(次回アクセス時に復元)

## 使い方

1. `index.html` をブラウザで開く(ビルド不要・依存ライブラリなし)
2. 「テンプレートCSVをダウンロード」でひな形を取得し、金額を入力する
3. できあがったCSVをドラッグ&ドロップする → CF計算書とチャートが表示される

まず「サンプル(270ファイル / 27社×10四半期)」ボタンで動作を確認するのがおすすめです。**会社×四半期ごとに1ファイル、計270ファイルを同時に読み込んだ状態**になるので、「データ」タブで元データをファイル単位で確認できます。1本にまとめたCSVは `sample-27.csv`、1社1期版は `sample.csv` にあります。

## 複数社・複数四半期を読み込む

読み込ませ方は2通りあり、どちらでも同じ結果になります。

1. **1ファイルにまとめる** — `会社名` と `四半期` の列を追加して行を並べます。空欄のセルは直前の行から引き継ぐので、社名や四半期は各ブロックの先頭行だけでも構いません。
2. **1社1ファイル** — `会社名` 列のないCSVを複数選択(またはまとめてドロップ)します。**ファイル名(拡張子を除く)が会社名**になります。

読み込むと上部に**会社**と**四半期**のセレクタが出ます(それぞれ2つ以上あるときだけ表示)。選ぶと画面全体が連動します。

### 画面の構成

会社・四半期のセレクタの下が7つのタブに分かれています。タブは矢印キー(← → Home End)でも切り替えられます。

| タブ | 内容 |
|---|---|
| **サマリー** | 選択中の会社・四半期の財務指標を、**前年同期**と並べて増減・増減率つきで表示。前年同期は「同じ四半期の1年前」を探し、四半期表記が解釈できない場合は4つ前の期で代用します |
| **推移** | 選択中の会社の預け金・借入金の直近10四半期を折れ線で表示。「前四半期差」に切り替えると増減額を縦棒で表示します |
| **CF計算書** | 選択中の会社・四半期のウォーターフォール、CF計算書、整合性チェック |
| **全社比較** | 選択中の四半期について、指標を切り替えられるランキングチャートと会社別サマリー表。見出しクリックで並べ替え、行やバーのクリックでその会社のサマリーへ移動します |
| **データ** | アップロードしたCSVをそのまま表形式でプレビュー |
| **詳細入力** | 精度を上げる詳細情報の入力と、テンプレートCSVのダウンロード/アップロード |
| **算定ロジック** | 選んだ行の算定元の図示と、簡便法の仮定 |

「推移」タブは2四半期以上、「全社比較」タブは2社以上あるときだけ表示されます。

### データタブ(CSVプレビュー)

CSVをExcelで開かなくても、アップロードした中身をそのまま確認できます。

- CSVの見出しと値をそのまま表示します。行番号は警告メッセージが指す行番号と対応しているので、指摘された行をそのまま探せます。
- 既定では**選択中の会社・四半期の行だけ**に絞り込みます。チェックを外すと全行を表示します。
- 行数が多い場合は200行ずつ表示し、「さらに500行を表示」で読み進められます。
- 複数ファイルを読み込んだときは、**選択中の会社・四半期を含むファイルが自動で開きます**。手動でファイルを選ぶとその選択が優先され、会社や四半期を変えると再び自動選択に戻ります。
- 空欄のセルは `—`、数値として読めるセルは右寄せで表示します。

### 算定ロジックタブ

**BS・PL・SSだけではCF計算書は作れません。** 足りない情報を簡便法の仮定で埋めているため、その中身を明示するタブです。

- **行を選ぶと算定元を図示** — CF計算書の行を選ぶと、算定に使う科目が左に並び、それぞれに **+ / −** のバッジが付きます。線でつながった中央が選んだ行、右がその行の反映先(営業CF/投資CF/財務CF、そして期末残高)です。データを読み込んでいれば各ノードに実際の金額も表示します。
- **各行の算式一覧** — 全行をまとめて確認できます。詳細情報を入れた場合の算式も併記します
- **簡便法の仮定** — 影響度つき。詳細入力タブで解消できるものには「→」で解消方法を示します

とくに重要な点として、**「CF計算書とBSの現金残高の整合」チェックは金額の妥当性を保証しません**。BSが両期で貸借一致し、SSと純資産増減が整合していれば数学的に必ず成立するためです(CFをBSの差額から逆算しているため)。たとえば減価償却費を誤ると営業CFと投資CFの配分がずれますが、チェックはすべてOKのままです。

記載が実装とずれないよう、次の2点を自動テストで検証しています。

1. `computeCF()` が出力しうる行名をすべて網羅していること(詳細情報の有無の両方で確認)
2. **記載した符号が実際の計算と一致すること** — 各入力を +δ したときに、その行が記載どおり ±δ 動くかを72件すべてで数値検証

### 詳細入力タブ

BS・PL・SSから読み取れない情報を補って、簡便法の仮定を減らします。

| グループ | 入力項目 | 何が変わるか |
|---|---|---|
| 現金同等物の範囲 | 現金同等物に含めない預金(期首・期末) | 3か月超の定期預金などを除きます。**増減額と期末残高そのものが変わり**、その資金移動は投資活動(定期預金の預入・払戻)になります |
| 総額表示 | 短期/長期借入れによる収入・返済による支出 | 「純増減額」1行が2行に分かれます。収入 − 支出 がBSの増減と一致しない場合は純額のままにし、警告を出します |
| 非資金項目 | 減損損失、固定資産除却損、ファイナンスリースによる資産取得額 | 減損・除却は営業CFで足し戻し、同額を有形固定資産の取得額から除きます(営業↔投資の振替)。リースは取得額と長期借入れの双方から除き、注記に別掲します(投資↔財務の振替) |
| その他 | 現金及び現金同等物に係る換算差額 | 税引前当期純利益に含まれる為替差損益を営業CFから消去し、同額を3区分の外に独立の行として置きます(会計基準どおりの表示) |
| 実際の受払額 | 利息及び配当金の受取額、利息の支払額、法人税等の支払額 | 小計より後の行が実額に置き換わります。発生額との差(未収利息・未払利息・未払法人税等の増減)は、その他流動資産／負債の増減の行から取り除いて二重計上を防ぎます |
| 表示区分 | 利息及び配当金をどの区分に置くか | 日本基準で認められた2方式を切り替えます。会計方針の選択であり、区分間の振替なので増減額は変わりません |

### 何が変わって、何が変わらないか

- **営業CF・投資CF・財務CFの各合計は変わります。** 区分間の振替が起きるためで、それが分類の是正です。
- **増減額と期末残高は原則として変わりません。** BSと articulate する事実だからです。
- ただし**「現金同等物の範囲」だけは増減額そのものを変えます。** 現金同等物の定義が変わるので、これも正しい挙動です。

会計上の恒等式

```
営業CF + 投資CF + 財務CF + 換算差額 = Δ(現金及び預金 − 現金同等物に含めない預金)
```

が、詳細情報のあらゆる組み合わせで成立することを自動テストで検証しています(`verify-articulation.js` 相当)。ただしこの恒等式は **BSが両期で貸借一致し、SSと純資産増減が整合している** ことが前提です。

入れ方は2通りです。

1. **画面で直接入力** — 選択中の会社・四半期について、フォームに入力すると即座に反映されます。入力した値はブラウザに保存され、再訪時に復元されます。「現金同等物に含めない預金」は期首・期末の2時点が必要なため、まとめて入れる場合はBSの科目として本体のCSVに行を追加してください(四半期をまたぐ引き継ぎも効きます)。
2. **テンプレートCSVで一括** — 読み込み済みの会社・四半期をすべて並べたCSVをダウンロードし(画面上でプレビューもできます)、金額欄に記入してアップロードします。会社名と四半期が一致する行に上書きで反映し、既存のBS・PL・SSはそのまま残ります。該当しない指定は読み飛ばして件数を報告します。

詳細情報は通常のCSVに `区分=詳細` の行として混ぜても読み込めます(科目名は別名にも対応)。

### 四半期の扱い

- `四半期` 列は `2025Q1` / `FY2025Q1` / `2025年度第1四半期` / `2025年1Q` / `1Q2025` / `2025-03` などの表記を解釈します。解釈できない表記はそのまま名前として使い、並び順は文字列順になります。
- **2四半期目以降は `前期末` 列を省略できます。**直前の四半期の期末残高を期首として自動で引き継ぎ、その旨を警告として表示します。
- 最初の四半期に期首BSがない場合、その四半期だけCF計算書を作成できません(指標の表示は可能です)。`前期末` 列を入れるか、1つ前の四半期のデータを足してください。

同じ会社名・同じ四半期のデータが複数の箇所に出てきた場合は、同一科目の重複行と同じように**合算**して扱い、警告を表示します。

## 財務指標の定義

| 指標 | 定義 |
|---|---|
| EBITDA | 営業利益 + 減価償却費 |
| EBITDAマージン | EBITDA ÷ 売上高 |
| ROIC | NOPAT(年換算) ÷ 投下資本(期首期末平均) |
| NOPAT | 営業利益 × (1 − 実効税率) |
| 投下資本 | 有利子負債 + 純資産 |
| 運転資金 | 売上債権 + 棚卸資産 − 仕入債務 |
| 有利子負債 | 短期借入金 + 長期借入金 |
| ネット有利子負債 | 有利子負債 − (現金及び預金 + 預け金) |
| 自己資本比率 | 純資産 ÷ 総資産 |
| フリーCF | 営業CF + 投資CF |

- **実効税率**は「法人税等 ÷ 税引前当期純利益」の実績値を使います。赤字や0〜60%の範囲外になる場合は30%を用います。
- **ROICの年換算**は、直近4四半期が揃っていればその合計(TTM)、揃わなければ当四半期の4倍を使います。どちらを使ったかは指標名の下に表示します。年次データの場合はそのままの値です。
- **営業利益**がCSVにない場合は「税引前当期純利益 + 支払利息 − 受取利息」で推計し、その旨を画面に表示します。EBITDAとROICもこの推計値に基づきます。
- 増減の色は「増えたか」ではなく「良くなったか」で付けます(有利子負債の減少は改善として緑)。良し悪しが一概に言えない運転資金・預け金には色を付けません。

ローカルでサーバーを立てる場合:

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

### GitHub Pagesで公開する場合

リポジトリの Settings → Pages で、ブランチを選んで公開するだけで動作します(静的サイトのため追加設定は不要)。

## CSVの書式

1行目に見出し、2行目以降に科目と金額を並べた**縦持ち形式**です。

```csv
会社名,四半期,区分,科目,前期末,当期末
アルファ工業,2025Q1,BS,現金及び預金,11700,15900
アルファ工業,2025Q1,BS,預け金,4000,4600
アルファ工業,2025Q1,PL,売上高,,52000
アルファ工業,2025Q1,SS,剰余金の配当,,1800
アルファ工業,2025Q2,BS,現金及び預金,,17200
ブライト電機,2025Q1,BS,現金及び預金,8000,9500
```

- **`会社名` 列は任意**です。省略した場合はファイル名を会社名として扱います。空欄の行は直前の行の会社名を引き継ぎます。
- **`四半期` 列は任意**です。省略した場合は全体を1期(通期)として扱います。空欄の行は直前の行の四半期を引き継ぎます。
- **`区分` 列は任意**です(読み飛ばします)。科目名から自動で振り分けます。
- **BSは前期末・当期末の2列**、**PL・SS・補足情報は当期末の列だけ**を使います。2四半期目以降は前期末を省略できます。
- 見出しの名前には幅があります — 科目列は `科目` / `項目` / `勘定科目` / `変動事由`、金額列は `前期末` / `前期` / `期首`、`当期末` / `当期` / `期末` / `金額`、四半期列は `四半期` / `期` / `期間` / `決算期` などが使えます。
- 見出し行より上にタイトル行や単位の行があっても読み飛ばします。見出し行がない場合は列位置を推定します。
- 区切り文字はカンマとタブ(TSV)の自動判定です。`#` で始まる行はコメントとして無視します。
- 金額は `1,234` / `¥1,234` / `△1,234` / `▲1,234` / `(1,234)` / `-1,234` / 全角数字のいずれでも読み取れます。
- **同じ会社の同じ科目に複数行あれば合算します**(例:`受取手形` と `売掛金` の2行 → `売上債権`)。
- 認識できなかった科目の行(小計行など)は読み飛ばし、画面に一覧で表示します。
- SS・補足情報の金額は、**支出・減少項目もすべて正の値**で入力してください(負の値は絶対値として扱い、警告を表示します)。

## 計算ロジック(間接法)

### 営業活動によるキャッシュ・フロー

税引前当期純利益に以下を加減算します。

- 減価償却費(+)
- 受取利息及び受取配当金(−)/ 支払利息(+)
- 固定資産売却損益(益は−、損は+)
- 売上債権・棚卸資産・その他流動資産の増減(増加は−)
- 仕入債務・その他流動負債の増減(増加は+)
- 小計の後、利息及び配当金の受取額(+)、利息の支払額(−)、法人税等の支払額(−)

### 投資活動によるキャッシュ・フロー

- 有形固定資産の取得による支出 — `期末純額 − 期首純額 + 減価償却費 + 売却簿価` で逆算(売却簿価 = 売却収入 − 売却損益)
- 有形固定資産の売却による収入(補足情報から)
- 投資その他の資産の増減(BS差額の純額)
- 預け金の増減(BS差額の純額)

### 財務活動によるキャッシュ・フロー

- 短期借入金・長期借入金の増減(BS差額の純額)
- 株式の発行による収入、自己株式の取得・処分、配当金の支払額(SSから)

### 簡便法としての前提

詳細情報を入力していない場合の既定の扱いです(詳細入力タブで解消できます)。

- 利息・配当金・法人税等の受払額は経過勘定を考慮せず、PLの発生額をそのまま使用
- 借入金・投資その他の資産・預け金は純額表示
- 有形固定資産の取得額は残高差からの逆算(除却・減損・リース取得が混ざる)
- 預け金は現金同等物に含めず、その増減を投資活動に表示
- 現金及び現金同等物 = BSの「現金及び預金」(「現金同等物に含めない預金」を入力すれば差し引きます)
- 連結範囲の変動に伴う現金の増減は未対応

```
js/app.js                  # CF計算ロジックと画面の描画

```

サンプルを編集したら、次のコマンドで再生成します(Node.jsのみ、依存パッケージなし)。

```bash
node scripts/gen-sample-27.js   # 27社×10四半期のデータを作り直す場合のみ
node scripts/build-samples.js   # sample*.csv を js/samples.js に埋め込む
```

`file://` で直接開いても動くように、サンプルCSVは `fetch` せず JavaScript に埋め込んでいます。

# CF-visualization

貸借対照表(BS)・損益計算書(PL)・株主資本等変動計算書(SS)をまとめた**CSVファイルをアップロード**すると、間接法によるキャッシュ・フロー計算書(CF計算書)を自動作成してWebページ上に表示する静的Webアプリです。**複数社をまとめて読み込んで比較**することもできます。

## 機能

- **CSVアップロード** — ドラッグ&ドロップまたはファイル選択。BS・PL・SSを1つのファイルにまとめて読み込みます
- **複数社の一括読み込み** — `会社名` 列を入れれば1ファイルに何社でも。1社1ファイルのCSVを複数選択してもまとめて読み込みます
- **全社比較ビュー** — 会社別サマリー表(並べ替え可)と、指標を切り替えられるランキングチャート
- **文字コード自動判定** — UTF-8(BOM有無どちらも)と Shift_JIS(Excel保存のCSV)に対応
- **表記ゆれの吸収** — 科目名の別名、`△1,234` / `(1,234)` / `¥1,234` / 全角数字などの金額表記に対応
- **CF計算書の自動生成(間接法)** — 営業・投資・財務の3区分と小計・期首/期末残高を自動計算
- **ウォーターフォールチャート** — 期首残高 → 営業CF → 投資CF → 財務CF → 期末残高の推移を可視化(ホバーで詳細表示)
- **整合性チェック** — BSの貸借一致、CF計算書とBSの現金残高の一致、SSと純資産増減の整合を会社ごとに自動検証
- **テンプレートCSVのダウンロード** — 空欄のひな形を出力。読み込んだ内容をCSVに書き戻すこともできます
- **ダークモード対応**・**入力の自動保存**(次回アクセス時に復元)

## 使い方

1. `index.html` をブラウザで開く(ビルド不要・依存ライブラリなし)
2. 「テンプレートCSVをダウンロード」でひな形を取得し、金額を入力する
3. できあがったCSVをドラッグ&ドロップする → CF計算書とチャートが表示される

まず「サンプル27社を読み込む」ボタンで動作を確認するのがおすすめです(同じ内容が `sample-27.csv`、1社版が `sample.csv` にあります)。

## 複数社を読み込む

読み込ませ方は2通りあり、どちらでも同じ結果になります。

1. **1ファイルにまとめる** — `会社名` 列を追加して、社ごとに行を並べます。空欄の `会社名` は直前の行から引き継ぐので、社名は各社の先頭行だけでも構いません。
2. **1社1ファイル** — `会社名` 列のないCSVを複数選択(またはまとめてドロップ)します。**ファイル名(拡張子を除く)が会社名**になります。

2社以上を読み込むと、画面上部に**全社比較**が表示されます。

- **ランキングチャート** — 営業CF / 投資CF / 財務CF / フリーCF / 現金の増減額 / 期末現金残高 から指標を選べます。バーをクリックするとその会社の明細に切り替わります。
- **会社別サマリー表** — 見出しクリックで並べ替え。`整合` 列で、整合性チェックに引っかかった会社がひと目で分かります。
- 明細(BS/PL/SSの読み込み結果・CF計算書・ウォーターフォール)は、選択中の1社について表示されます。上部のセレクタか、表・チャートのクリックで切り替えられます。

同じ会社名が複数の箇所に出てきた場合は、同一科目の重複行と同じように**合算**して1社として扱い、警告を表示します。

ローカルでサーバーを立てる場合:

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

### GitHub Pagesで公開する場合

リポジトリの Settings → Pages で、ブランチを選んで公開するだけで動作します(静的サイトのため追加設定は不要)。

## CSVの書式

1行目に見出し、2行目以降に科目と金額を並べた**縦持ち形式**です。

```csv
会社名,区分,科目,前期末,当期末
アルファ工業,BS,現金及び預金,12000,7900
アルファ工業,BS,売上債権,18000,21000
アルファ工業,PL,税引前当期純利益,,9000
アルファ工業,補足,有形固定資産の売却による収入,,1800
アルファ工業,SS,剰余金の配当,,1800
ブライト電機,BS,現金及び預金,8000,9500
```

- **`会社名` 列は任意**です。省略した場合はファイル名を会社名として扱います。空欄の行は直前の行の会社名を引き継ぎます。
- **`区分` 列は任意**です(読み飛ばします)。科目名から自動で振り分けます。
- **BSは前期末・当期末の2列**、**PL・SS・補足情報は当期末の列だけ**を使います。
- 見出しの名前には幅があります — 科目列は `科目` / `項目` / `勘定科目` / `変動事由`、金額列は `前期末` / `前期` / `期首`、`当期末` / `当期` / `期末` / `金額` などが使えます。
- 見出し行より上にタイトル行や単位の行があっても読み飛ばします。見出し行がない場合は列位置を推定します。
- 区切り文字はカンマとタブ(TSV)の自動判定です。`#` で始まる行はコメントとして無視します。
- 金額は `1,234` / `¥1,234` / `△1,234` / `▲1,234` / `(1,234)` / `-1,234` / 全角数字のいずれでも読み取れます。
- **同じ会社の同じ科目に複数行あれば合算します**(例:`受取手形` と `売掛金` の2行 → `売上債権`)。
- 認識できなかった科目の行(小計行など)は読み飛ばし、画面に一覧で表示します。
- SS・補足情報の金額は、**支出・減少項目もすべて正の値**で入力してください(負の値は絶対値として扱い、警告を表示します)。

## 計算ロジック(間接法)

### 営業活動によるキャッシュ・フロー

税引前当期純利益に以下を加減算します。

- 減価償却費(+)
- 受取利息及び受取配当金(−)/ 支払利息(+)
- 固定資産売却損益(益は−、損は+)
- 売上債権・棚卸資産・その他流動資産の増減(増加は−)
- 仕入債務・その他流動負債の増減(増加は+)
- 小計の後、利息及び配当金の受取額(+)、利息の支払額(−)、法人税等の支払額(−)

### 投資活動によるキャッシュ・フロー

- 有形固定資産の取得による支出 — `期末純額 − 期首純額 + 減価償却費 + 売却簿価` で逆算(売却簿価 = 売却収入 − 売却損益)
- 有形固定資産の売却による収入(補足情報から)
- 投資その他の資産の増減(BS差額の純額)

### 財務活動によるキャッシュ・フロー

- 短期借入金・長期借入金の増減(BS差額の純額)
- 株式の発行による収入、自己株式の取得・処分、配当金の支払額(SSから)

### 簡便法としての前提

- 利息・配当金・法人税等の受払額は経過勘定を考慮せず、PLの発生額をそのまま使用
- 現金及び現金同等物 = BSの「現金及び預金」

## ファイル構成

```
index.html                 # 画面(アップロード・全社比較・明細)
sample.csv                 # サンプルデータ(1社)
sample-27.csv              # サンプルデータ(27社)
css/style.css              # スタイル(ライト/ダークテーマ)
js/schema.js               # 科目定義と別名
js/csv.js                  # CSVの文字コード判定・解析・会社と科目の割り当て
js/samples.js              # サンプルCSVの埋め込み(自動生成)
js/app.js                  # CF計算ロジック・全社比較と明細の描画
scripts/gen-sample-27.js   # sample-27.csv を生成する
scripts/build-samples.js   # sample*.csv から js/samples.js を生成する
.github/workflows/pages.yml # GitHub Pagesへの自動デプロイ
```

サンプルを編集したら、次のコマンドで再生成します(Node.jsのみ、依存パッケージなし)。

```bash
node scripts/gen-sample-27.js   # 27社のデータを作り直す場合のみ
node scripts/build-samples.js   # sample*.csv を js/samples.js に埋め込む
```

`file://` で直接開いても動くように、サンプルCSVは `fetch` せず JavaScript に埋め込んでいます。

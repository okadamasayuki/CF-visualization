# CF-visualization

貸借対照表(BS)・損益計算書(PL)・株主資本等変動計算書(SS)を入力すると、**間接法によるキャッシュ・フロー計算書(CF計算書)を自動作成**してWebページ上に表示する静的Webアプリです。

## 機能

- **BS・PL・SSの入力フォーム** — BSは前期末・当期末の2期分を入力
- **CF計算書の自動生成(間接法)** — 営業・投資・財務の3区分と小計・期首/期末残高を自動計算
- **ウォーターフォールチャート** — 期首残高 → 営業CF → 投資CF → 財務CF → 期末残高の推移を可視化(ホバーで詳細表示)
- **整合性チェック** — BSの貸借一致、CF計算書とBSの現金残高の一致、SSと純資産増減の整合を自動検証
- **サンプルデータ** — ワンクリックで整合の取れたサンプルを読み込み
- **入力の自動保存** — ブラウザのlocalStorageに保存され、再訪時に復元
- **ダークモード対応** — OSの設定に自動追従

## 使い方

1. `index.html` をブラウザで開く(ビルド不要・依存ライブラリなし)
2. BS(前期末・当期末)、PL、SS、補足情報を入力する
3. 入力と同時にCF計算書とチャートが自動で更新される

まず「サンプルデータを読み込む」ボタンで動作を確認するのがおすすめです。

ローカルでサーバーを立てる場合:

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

### GitHub Pagesで公開する場合

リポジトリの Settings → Pages で、ブランチを選んで公開するだけで動作します(静的サイトのため追加設定は不要)。

## 計算ロジック(間接法)

### 営業活動によるキャッシュ・フロー

税引前当期純利益に以下を加減算します。

- 減価償却費(+)
- 受取利息及び受取配当金(−)/ 支払利息(+)
- 固定資産売却損益(益は−、損は+)
- 売上債権・棚卸資産・その他流動資産の増減(増加は−)
- 仕入債務・その他流動負債の増減(増加は+)
- 小計の後、利息及び配当金の受取額(+)、利息の支払額(−)、法人税等の支払額(−)

### 投資活動によるキャッシュ・フロー

- 有形固定資産の取得による支出 — `期末純額 − 期首純額 + 減価償却費 + 売却簿価` で逆算(売却簿価 = 売却収入 − 売却損益)
- 有形固定資産の売却による収入(補足情報から)
- 投資その他の資産の増減(BS差額の純額)

### 財務活動によるキャッシュ・フロー

- 短期借入金・長期借入金の増減(BS差額の純額)
- 株式の発行による収入、自己株式の取得・処分、配当金の支払額(SSから)

### 簡便法としての前提

- 利息・配当金・法人税等の受払額は経過勘定を考慮せず、PLの発生額をそのまま使用
- 現金及び現金同等物 = BSの「現金及び預金」
